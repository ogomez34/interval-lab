THE 3 FAMILIES

  • PERFECT
    unison · 4th · 5th · octave — hollow, strong, stable. The frame of the building.
  • IMPERFECT
    3rds · 6ths — the colours. Major = bright, minor = dark. They make chords happy or sad.
  • DISSONANT
    2nds · 7ths · tritone — tension that wants to resolve. Melodies and blues live here.

DERIVE — DON’T MEMORISE

  • Pick 1 — any note, any string. “1” is home.
  • Count steps → intervals (3 frets = ♭3).
  • 4 notes spanning a 4th → a tetrachord.
  • Lower + gap + upper → a scale. No table needed.
  • 1st + 3rd note of each half → the 7th chord inside the scale.
  • Stack 5ths → the circle of fifths, keys, everything.

THE GUITAR TRICK · TWO MAGIC SHAPES

Tetrachord: the 4 sits right above 1 — same fret, next string
Octave: the 8 is 2 strings up + 2 frets
Across the G→B pair add 1 fret — those two strings are a major 3rd apart, not a perfect 4th. Everything else on the neck is a perfect 4th.

CIRCLE OF 5THS · STACK THEM UP

CAm GEm DBm AF♯m EC♯m BG♯m
F♯E♭m D♭B♭m A♭Fm E♭Cm B♭Gm FDm
Top = major key · bottom = its relative minor. Same slice = same notes. Each 5th up adds a ♯, each 5th down adds a ♭ — after F it wraps back to C.

THE RULER — the top row is every distance from any fret you pick as 1. Slide it anywhere; the labels never change. 1 fret = 1 semitone.
OCTAVE TWINS — the same note sits 2 strings up + 2 frets away. Cross the major-3rd pair (G→B · F→A) and add +1 fret. Find one copy, find them all.
FRET-5 RULE — the next string's open note = this string at fret 5 — fret 4 across the major-3rd pair. That single rule builds both tunings.
FRET 12 = OCTAVE — every string repeats after 12 frets, so this board is the whole neck, forever. Note names: white = natural · amber = ♯/♭ · C♯ = D♭.
